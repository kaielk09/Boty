# PurpleSchematic

Repozytorium jest teraz przeznaczone dla projektu PurpleSchematic — aplikacji desktopowej do importowania schematów i budowania w Minecraft.

- [Dokumentacja i instrukcja uruchomienia](purpleschematic/README.md)
- [Aplikacja desktopowa](purpleschematic/)
- [Adapter Minecraft Java 1.20.1 + Fabric](purpleschematic/adapter-fabric/)

Poprzedni projekt botów Minecraft został usunięty. Pierwsza wersja integracji ma ograniczoną obsługę formatów i wersji gry; szczegóły znajdują się w dokumentacji.
